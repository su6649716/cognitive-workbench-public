# 认知助手 · Cognitive Workbench

面向 AI 助手的项目协作 Skill：恢复项目背景、判断实施路线、检查系统联动、追踪假设，并以实际结果完成验收与收口。

当前维护版本为 **2.4.1**，位于 [`versions/2.4`](../../tree/versions/2.4)。`main` 保留早期版本。

## 使用

将 `versions/2.4` 分支的仓库放入宿主支持的 Skill 目录，命名为 `cognitive-workbench`，按宿主机制加载 `SKILL.md`。可以直接说“启动认知助手”或“认知一下这个方案”。需要宿主具备读取文件和执行脚本的能力；状态脚本使用 Python 3.10+，工程检查和同步另需 Git。

规则入口见 [SKILL.md](SKILL.md)。当前版本的运行说明见 [`references/runtime-contract.md`](../../blob/versions/2.4/references/runtime-contract.md)。

## 隐私

本仓库公开的是 Skill 源码、模板和合成测试。项目索引、事件账本、真实聊天、自动任务及备份属于个人状态，不随源码公开。

2.4 默认状态目录为 `~/.cognitive-workbench/`，不会自动导入旧状态。远端状态备份需要单独指定私有仓库并授权同步。请勿把真实状态或凭据复制进本仓库。

公开前已对各分支和标签的可达历史进行脱敏：私人邮箱改用 GitHub 隐私邮箱，本机绝对路径改为占位符，私人使用审查正文改为公开说明。历史提交编号因此发生变化；已有克隆建议重新克隆，避免重新推入旧历史。
