# 代码项目工程基线

仅当前任务实际修改代码且认知助手已触发时执行。只读审计、非代码工作、普通问答不初始化 Git，不自动写项目索引。

本文件是 **Git 工程基线**；“架构/UI/接口/运行采用什么具体值”由 [项目工程约定](project-baseline.md)负责。需要新增约定时在同一次施工中处理，不为此重复初始化 Git 或建立认知事件。

## 修改前

先定位实际项目根。用户要求独立全新建设且不动原项目时，在独立目标目录施工，不将旧仓库自动选为写入位置；维护任务在已有仓库根施工。多项目集合选目标子项目，不在集合目录建总仓库。新项目/模块/重构读架构基线。运行 `python3 <SKILL_DIR>/scripts/git_project_guard.py --path <project>`；确实缺 Git 且初始化属已授权任务时追加 --init-if-missing，不绕过拒绝。

核对 .gitignore、敏感/产物路径、真实分支或 detached 状态、HEAD、远程和脏改动。记录目标、验收、起点 HEAD、用户原有修改、本轮路径及禁改边界。已有事件可保存在 metadata.engineering_baseline，否则保留当前任务，不为此新建事件。

项目根已核实且允许持久化才 upsert。中高风险样板/完整实施按共同定义与 project_index.py gate，不用 Git 就绪替代产品语义确认。

## 实施保护

只修改任务所需路径，保留用户既有脏改动；不暂存、提交或还原无关内容。不用 git add .、git add -A 或通配符。初始化后完善忽略规则，不提交凭证、依赖、构建产物和本地数据库。未知文件阻断首次提交而非草率收进去。

已验证可运行的阶段可本地提交，不造失败/WIP检查点。遵守宿主和用户现有策略；原本 codex.autoCommit=false 继续有效，“不要提交”优先。Skill 不能独立扩大授权。

## 收口

完成风险相称的测试/构建、受影响接口与结构回归；git diff --check；确认本轮和原有改动可安全分离；只暂存本轮路径并检查实际 staged diff。测试失败、疑似秘密、不可分离或用户禁提时不提交。

按原项目策略作本地提交后运行：

```text
python3 <SKILL_DIR>/scripts/git_project_guard.py --path <project> --check-close \
  --baseline-head <起点SHA或NONE> --task-path <本轮路径>
```

必须解析 closure.ready，退出零只证明检查命令运行成功。只有验收通过、任务路径无脏改动、HEAD确实前进且起点是祖先、提交包含本轮路径，才称工程已收口。读取失败是未知，不是干净；detached HEAD 如实记录。

未收口保留功能成果和具体原因，不制造额外报告。将检查点和结果写回原项目/事件；无用户真实使用证据不声称生产可用。

## 本地与远端分离

本地阶段提交与远端推送分开。只有明确推送请求或项目已有有效 codex.autoPush=true、目标远端分支明确且无待决定冲突时才推。不得擅建远端仓库、改远端地址或公开性；失败保留本地提交，不反复改历史。
