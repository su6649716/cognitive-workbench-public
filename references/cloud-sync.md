# 私有云端同步

认知助手的源码与运行状态分开同步：

- Skill 源码由 `<SKILL_DIR>` 的源码 Git 仓库管理。
- 项目基线、事件账本、全局路由和自动任务由独立私有仓库 `cognitive-workbench-state` 管理。

用户明确要求云端同步，或仓库设置 `codex.autoPush=true` 时，在任务收口完成、本地文件已更新后运行：

```text
python3 scripts/sync_state.py --push
```

脚本先校验项目索引 JSON、事件账本 JSONL，并扫描常见密钥格式。发现疑似密钥时停止，不提交、不推送。没有状态变化时不创建空提交。推送失败时保留本地提交并明确报告，不能声称云端已经同步。

同步不是事务：Skill 仓库和状态仓库可能一个成功、一个失败。收口时分别报告两者的本地提交号和云端状态。

恢复时先克隆状态仓库，再比较本地与云端：

- 事件账本按事件 ID 和追加更新时间合并；不直接覆盖本地文件。
- 项目索引按项目 ID 合并，并复核 `baseline_source`、`baseline_status` 和当前事实。
- 全局 AGENTS 与自动任务先显示差异，再选择适用内容。
- 云端旧快照不能覆盖本机较新的决定；来源或适用项目不清楚时保持待核对。

私有仓库仍属于外部存储。不要把 API Key、令牌、密码、私钥或含凭证的环境文件加入同步范围。
