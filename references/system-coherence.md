# 系统一致性与目的规划：广思考，窄执行

## 六项规划主线

先从当前原话、明确约束和真实结果建立规划。全新建设不把旧实现、旧基线或旧验收当作前提；维护时才核对相关现行决定：

| 项目 | 要回答的问题 |
|---|---|
| 最终要改变的现实 | 完成后用户的实际工作发生什么变化 |
| 当前交付物负责 | 在总目标中必须完成哪一段 |
| 当前交付物不负责 | 哪些相邻工作不能吞入本组件 |
| 必须尊重的真实规则 | 事实真源、不变量、数据与计算口径 |
| 连续使用路径 | 用户带什么输入，经过什么动作，到什么结果 |
| 完成证据 | 什么可观察结果证明当前职责成立 |

这是内部规划主线，不是让用户填表。明确区分用户原话、已确认内容、助手推断。主文件负责选择更合适实现与尊重确认的裁决；目的不明且高返工时用共同定义，不在这里重复设门。

检查结果与载体错位、父目标与组件错位、规则与对象错位：学习操作不必做成原文展示；服务上架不等于吞入上传发布；产品涨幅不能自动作用于包装快递。

## 恢复设计依据

全新建设先定当前目标和必要外部责任，旧项目材料仅供按需参考；不为继承旧设计恢复整条历史链。维护任务将当前纠正、有效产品文档、索引、实现与真实数据相互核对。文档和实现冲突时保留事实，按冲突对当前决定的影响处理；不默认任一方永远正确。

用 `scripts/project_index.py system` 取得父系统组件，确认当前角色、每类事实真源和业务链路。规划稳定后在允许写入时保存 `planning_baseline`；人机界面稳定后保存 `interface_baseline`。当前事实变化使旧基线 `stale/superseded`，只更新受影响层。

## 双向扫描

**横向角色闭环**：谁配置、谁录入/执行/修正、谁拥有结果、谁看个人结果、谁做管理判断；不同角色取得同一事实的合适视图，不能复制一套失真的口径。

**纵向数据闭环**：配置/主数据 → 输入 → 归属与状态 → 业务结果 → 个人视图 → 管理视图 → 下游协议/报告 → 复盘纠正。

仅展开本次相关的角色权限、对象与时间、来源归因、配置停用/删除和历史引用、未知/重复值、人工修正、导入、视图与下游观测。不因清单存在就增建移动端或整套平台。

## 必要承接与扩展分级

- **必要联动**：不处理会令当前逻辑错误、数据断链、权限失真、历史不可解释或下游口径不一致。进入设计；属于已授权当前职责且无新增重要取舍时实施，否则集中说明。
- **现在准备承接**：用稳定输出、字段、状态或接口交给下一步，不建设下游产品。
- **价值扩展**：当前功能没有它也能成立，未经确认不实施。
- **远期机会**：缺证据或离当前目标远，不占当前对话；有真实未来价值才按原机制保留。

## 纠正传播

识别纠正涉及目的、组件边界、真实规则、连续操作、形态/界面还是验收。更新该层规划并保留来源；删除被否定路线；扫描受影响对象、公式、状态、页面、文档、测试和验收；只实施修正后必要的范围。

技术补全可自行验证；改变已确认语义且有重要取舍时，按共同定义只回到受影响层，不把整项目推倒再问。新事实与原确认冲突时不能继续假装基线有效。

## 面向人的产品与施工

持续操作成品按 [interface-translation.md](interface-translation.md) 形成界面合同，具体 CSS、图表或应用实现交对应能力。高返工分叉按 [collaborative-definition.md](collaborative-definition.md) 展示真实选择、推荐和样板；使用 `scripts/project_index.py gate` 核对实施基线。

设计变化单只展示影响本次决定的内容：目标、职责、保持不变、变化、必要联动、交接、本轮最终实施范围和验收。没有额外联动就不强行编一个，也不汇报一串“检查过但没做”。

## 验收

实现仍服务规划主线；纠正已传播且旧路线不残留；相关横纵链路同口径；未知、历史、停用和恢复可解释；价值扩展未混入；界面能走完代表性路径。工程检查与业务成立分别报告。

## 场景例子

**获客与培训协同**：管理员和业务员视图不同；一个员工可能绑定多个微信；渠道与人员配置有停用、删除、历史引用；个人承接与管理汇总使用一致归因；保留经营观测组件的只读下游协议。智能建议和视觉美化不能自动加入。

**新增任务状态**：检查谁产生、谁修改、视图如何解释、历史是否保留及同步/报表口径。

**接入新数据源**：检查事实真源、读写边界、时区、未知与重复、归属及下游“无数据不等于零”。

**成本表服务上架**：保留产品识别、固定组合/SKU、成本与定价；上传发布留给下游，仅交付稳定字段。

**课程转操作工具**：从状态变化、通关、失败退路、上下步承接选择地图、向导、工作台等形态，不默认原文摘要加一排计算器。
