# 十三项能力在工作流中的位置

原名称、用途与组织保留。它们是按问题选用的认知方法，不是十三个并列 Skill，也不是必跑检查表。

| 能力 | 局部作用 | 主要工作流 |
|---|---|---|
| 信息溯源 | 追踪判断依据和来源距离 | 收口、假设、项目复盘 |
| 信息压缩 | 保留决定行动的最小充分结构 | 扩张检查、收口 |
| 事实观点拆分 | 分开观察、解释、预测和决定 | 假设、收口 |
| MECE拆解 | 建立与当前决定有关的问题空间；扫描传播层 | 扩张检查、项目复盘 |
| 因果分离 | 形成竞争解释和区分证据 | 假设、收口 |
| 逆向推演 | 找出失败路径和致命条件 | 扩张检查 |
| 链式推导 | 观察动作上下游与连锁影响 | 扩张检查、项目复盘 |
| 第一性原理 | 从父系统目标、约束和不变量重建方案 | 扩张检查 |
| 假设验证 | 用现实动作降低不确定性 | 假设、扩张检查 |
| 瓶颈识别 | 找到当前最值得释放的约束 | 扩张检查、项目复盘 |
| 机会成本 | 比较放弃的最佳替代项 | 扩张检查、项目复盘 |
| 止损预设 | 事前绑定未来的停止动作 | 扩张检查、假设、项目复盘 |
| 正反论证 | 寻找能推翻偏好路线的证据 | 扩张检查、收口、项目复盘 |

## 选择参考

扩张检查可选问题拆解、失败推演、瓶颈；目的推断时第一性原理，路线竞争时正反论证，取舍时机会成本与止损。
假设可选因果分离、事实观点拆分与最小验证；长期测试加止损，多变量加链式推导并明确归因限制。
收口可选压缩、溯源、正反论证；跨项目复用时拆分事实与观点。
多项目复盘可选瓶颈、机会成本、止损；上下游依赖时链式推导。

选用依据是当前困难与预期改变的决定，不固定“起手三件套”。主动解题提供方法何时参与选路的共同责任，不另造第十四种必跑方法。

有必要说明时只给二至四条可核对的“方法→事实证据→改变的交付/范围/验证”。没有改变决定就不声称用过，不要求私人推理过程或教学展示。
