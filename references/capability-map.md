# 十三项能力在工作流中的位置

这些能力是局部认知算子，不是十三个并列Skill，也不要求一次全部使用。

| 能力 | 局部作用 | 主要工作流 |
|---|---|---|
| 信息溯源 | 追踪判断依据和来源距离 | 收口、假设、项目复盘 |
| 信息压缩 | 保留决定行动的最小充分结构 | 扩张检查、收口 |
| 事实观点拆分 | 分开观察、解释、预测和决定 | 假设、收口 |
| MECE拆解 | 建立与当前决定有关的问题空间；扫描系统传播层 | 扩张检查、项目复盘 |
| 因果分离 | 形成竞争解释和区分证据 | 假设、收口 |
| 逆向推演 | 找出失败路径和致命条件 | 扩张检查 |
| 链式推导 | 观察动作的上下游与后续连锁影响 | 扩张检查、项目复盘 |
| 第一性原理 | 从父系统目标、约束和不变量重建方案 | 扩张检查 |
| 假设验证 | 用现实动作降低不确定性 | 假设、扩张检查 |
| 瓶颈识别 | 找到当前最值得释放的约束 | 扩张检查、项目复盘 |
| 机会成本 | 比较被放弃的最佳替代项 | 扩张检查、项目复盘 |
| 止损预设 | 事前绑定未来的停止动作 | 扩张检查、假设、项目复盘 |
| 正反论证 | 主动寻找能推翻当前偏好路线的证据 | 扩张检查、收口、项目复盘 |

选择标准是当前认知困难，而不是能力覆盖率。输出必须落到局部结果：证据判断、最小验证、范围边界、保留结论或项目取舍。

在系统一致性分支中，这些算子服务于“恢复目标—双向扫描—联动分级—窄范围实施”，不是把十三项能力逐项展示给用户。
